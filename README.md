# Church Projector

App de escritorio para proyección en iglesias. Muestra letras de canciones, versículos bíblicos, imágenes, videos y GIFs en una segunda pantalla, con reproducción de música de fondo independiente.

**Plataformas:** Windows · Linux

## Stack

Electron · electron-vite · React 18 · TypeScript strict · Tailwind CSS · Zustand · Howler.js

## Inicio rápido

```bash
pnpm install
pnpm dev
```

Ver [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) para más detalle.
